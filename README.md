# Codex Account Switcher

macOS 메뉴 막대에서 Codex의 **퍼스널·비즈니스 계정 / 워크스페이스**를 등록하고 전환하는 작은 앱입니다. 같은 이메일의 퍼스널과 비즈니스도 각각 저장합니다.

[최신 버전 다운로드](https://github.com/corbie79/codex-switch/releases/latest)

## 설치

1. Releases에서 `Codex-Account-Switcher-…-macOS-arm64.zip`을 다운로드하고 압축을 풉니다.
2. `Codex Account Switcher.app`을 응용 프로그램 폴더로 옮겨 실행합니다.
3. 메뉴 막대의 **CX** 아이콘을 누릅니다.

macOS 13 이상, Apple Silicon(M1 이상), Codex 데스크톱 앱이 필요합니다. Codex의 번들 ID `com.openai.codex`로 설치 위치를 찾으며, 앱 이름이 `ChatGPT.app`인 설치도 지원합니다.

현재 배포본은 ad-hoc 서명이며 Apple 공증을 받지 않았습니다. 다운로드한 앱 실행이 차단되면 macOS 시스템 설정 → 개인정보 보호 및 보안에서 해당 앱의 실행을 허용해야 할 수 있습니다. 조직 정책으로 허용되지 않는 기기에서는 관리자에게 문의하세요. 소스에서 직접 빌드할 수도 있습니다.

## 퍼스널과 비즈니스 함께 등록하기

1. **＋ 퍼스널 / 비즈니스 등록…** → **퍼스널** → 브라우저 로그인. 브라우저에서 개인 워크스페이스를 선택합니다.
2. 다시 **＋ 퍼스널 / 비즈니스 등록…** → **비즈니스** → 브라우저 로그인. 회사 워크스페이스를 선택합니다.
3. 메뉴의 **퍼스널**, **비즈니스** 그룹에 저장된 항목을 선택하면 Codex가 종료된 후 해당 로그인으로 다시 실행됩니다.

각 워크스페이스의 최초 브라우저 로그인은 사용자가 직접 완료해야 합니다. 선택한 유형과 토큰에 표시된 유형이 다르면 등록을 거절합니다. 유형을 알 수 없는 로그인은 선택한 유형으로 분류되며, 자동 감지로 등록하면 ‘기타 / 미확인’에 표시됩니다. 유형 선택은 구독을 바꾸거나 워크스페이스를 생성하지 않습니다.

브라우저에서 원하는 워크스페이스를 고르기 어려우면 등록 창에 해당 **워크스페이스 ID(UUID)**를 입력할 수 있습니다. 입력한 ID는 로그인 요청에 적용되며, 로그인 결과가 그 ID와 일치해야 등록됩니다. 다른 이메일을 추가할 때는 브라우저의 계정 선택/로그아웃 기능을 사용하세요.

처음 실행할 때 현재 파일 기반 로그인도 자동으로 저장합니다. 기존 버전의 등록 목록은 계속 읽을 수 있으며, 현재 계정은 재감지합니다. 다른 기존 계정은 해당 계정으로 전환한 후 ‘현재 로그인 계정 저장’을 누르면 유형이 갱신됩니다.

## 전환 동작과 데이터

- 계정은 **사용자 ID + 워크스페이스 ID**로 구별합니다. 같은 이메일이나 같은 회사의 다른 사용자도 덮어쓰지 않습니다.
- 저장한 로그인 정보는 macOS 키체인에 보관합니다. 이름·분류 목록만 `~/Library/Application Support/Codex Account Switcher/profiles.json`에 기록합니다.
- 계정 추가는 별도 임시 로그인 폴더에서 진행하므로 현재 Codex 로그인 파일을 교체하지 않습니다. 정상 완료·실패·취소 후 임시 폴더를 지웁니다. 강제 종료 시 임시 폴더가 남을 수 있습니다.
- 전환 전에 현재 갱신된 로그인을 저장하고 Codex 종료를 기다립니다. 25초 안에 종료되지 않으면 로그인 파일 교체를 중단합니다.
- 활성 로그인 파일은 권한 `0600`으로 원자적으로 교체합니다. 재실행 요청이 실패하면 이전 로그인 파일을 복원합니다.
- 기본값은 **Codex만 재실행**입니다. VS Code도 재실행하려면 설정에서 켭니다. 별도로 실행한 Codex CLI는 먼저 직접 종료하세요.
- 이 도구는 Codex 작업 기록·프로젝트·설정을 삭제하거나 이전하지 않습니다. 같은 Codex 홈을 사용하므로 로컬 작업 데이터는 공유되며, 계정별 데이터 격리 도구는 아닙니다. 앱의 계정별 표시 여부는 Codex 동작에 따릅니다.
- GitHub 소스·배포 ZIP에는 사용자 계정, 키체인 데이터, 대화 기록을 포함하지 않습니다.

## 지원 범위

이 버전은 Codex의 **파일 기반 ChatGPT 인증(`auth.json`)**을 대상으로 합니다. `cli_auth_credentials_store = "keyring"` 또는 `"auto"` 환경, API 키 로그인은 지원 대상이 아닙니다. 기본 경로는 `~/.codex`이며 실행 환경에 `CODEX_HOME`이 있으면 그 경로를 사용합니다. Finder 실행은 터미널의 환경 변수를 자동으로 물려받지 않습니다.

관리자가 허용한 로그인 방식·워크스페이스 제한은 Codex에서 계속 적용됩니다. 제한과 충돌하는 계정은 사용할 수 없습니다. 토큰은 편집하거나 임의로 생성하지 않으며, 계정이 만료되면 다시 등록해야 합니다. 저장소는 OpenAI의 공식 제품이 아닙니다.

인증 저장 방식과 워크스페이스 제한: [OpenAI 공식 인증 문서](https://learn.chatgpt.com/docs/auth).

## 빌드와 검증

Xcode Command Line Tools가 설치된 Mac에서:

```sh
./scripts/test.sh
./scripts/test.sh --keychain-test  # 임시 테스트 키체인 항목 생성·갱신·삭제
./scripts/build.sh 0.1.0
```

`dist/`에 Apple Silicon 앱, ZIP, SHA-256 체크섬을 생성합니다. Apple 개발자 인증서나 실사용 로그인 없이 빌드할 수 있습니다.

자동 검사는 같은 사용자/다른 워크스페이스 및 다른 사용자/같은 워크스페이스의 식별, 구독 유형 분류, 워크스페이스 불일치 거부, 기존 목록 호환성을 검증합니다. 실제 브라우저 로그인과 Codex 재실행의 전체 경로는 별도 수동 확인이 필요합니다.

`main` 푸시와 PR에서는 GitHub Actions가 검사·빌드합니다. `v0.1.1` 같은 태그를 푸시하면 성공한 빌드의 ZIP과 체크섬이 GitHub Release에 자동 게시됩니다.
